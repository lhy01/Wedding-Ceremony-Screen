# 💍 浪漫婚礼大屏照片轮播系统 (Wedding Ceremony Screen)

基于 **Vue 3 + Vite + Pinia** 前端 与 **Node.js (Express + WebSocket)** 后端打造的高颜值、沉浸式婚礼大屏轮播展示与播控系统。

---

## 🌟 核心特色

1. **5 套流行婚礼视觉模板，支持一键切换**：
   - ✨ **浪漫法式香槟金 (`champagne-gold`)**：轻奢流金、金色粒子光晕、双人誓词、典雅衬线排版。
   - 🏮 **中式国潮吉庆红 (`chinese-classic`)**：朱砂红底、落红花瓣粒子、烫金祥云与双喜印章、琴瑟和鸣楹联。
   - 🌿 **极简轻奢白绿森系 (`forest-green`)**：尤加利绿、自然微风斑驳、文艺手写体与画报质感相框。
   - 📷 **复古拍立得时光 (`retro-polaroid`)**：倾斜拍立得纸框、手写体故事心语、和纸胶带与纪念邮戳。
   - 🌌 **现代梦幻星空幻境 (`starlight-dream`)**：午夜深蓝星河、梦幻霓虹紫粉光晕、3D 立体悬浮景深。

2. **丰富电影感转场动效**：
   - 经典 **Ken Burns** 电影缓慢推镜头与摇移。
   - **3D 立体悬浮翻转**。
   - **高斯模糊动态景深与艺术淡入淡出**。

3. **双端播控与实时通信 (WebSocket)**：
   - **大屏展示端 (`/`)**：全屏沉浸播放，悬浮遥控工具栏（自动隐藏），键盘快捷键（空格暂停、左右切图、F 全屏、M 音乐、B 弹幕）。
   - **管理后台 (`/admin`)**：大屏实时监播、一键切歌/切模板、照片批量拖拽上传、编辑故事与拍摄地、删除照片、重置预设图库、清空/审核弹幕。
   - **手机宾客祝福端 (`/bless`)**：现场亲友扫码即进，选择个性徽章，发送祝福弹幕即刻飞过大屏，支持一键献花撒礼花互动！

4. **零外部数据库依赖**：
   - 本地 JSON 持久化存储 + 本地上传图片静态托管，开箱即用，无需配置复杂的 MySQL/MongoDB。

## 🚀 快速启动

### 方式 1：一键同时启动全栈 (推荐)
在根目录下运行：
```bash
npm run dev
```

### 方式 2：分别启动
1. **启动后端服务 (端口 3000)**：
   ```bash
   cd server
   npm install
   npm run dev
   ```
2. **启动前端服务 (端口 5173)**：
   ```bash
   cd client
   npm install
   npm run dev
   ```

## ⌨️ 大屏快捷键速查

| 按键 | 功能说明 |
|:---|:---|
| **Space 空格** | 暂停 / 继续轮播 |
| **→ 右方向键** | 切换到下一张照片 |
| **← 左方向键** | 切换到上一张照片 |
| **F 键** | 进入 / 退出全屏展示模式 |
| **M 键** | 播放 / 暂停背景音乐 (BGM) |
| **B 键** | 开启 / 关闭现场祝福弹幕 |
